# Download and install

The latest version of the plug-in is natively distributed by Autodesk with the latest compatible version of 3ds Max. If you need a specific build for an older version, please find the download links below.

* **Download for Autodesk 3ds Max 2027:** <https://www.adobe.com/go/substance3d-3dsmax-win-latest>
* **Download for Autodesk 3dsMax 2026:** <https://www.adobe.com/go/substance3d-3dsmax-win-2026>
* **Download for Autodesk 3dsMax 2025:** <https://www.adobe.com/go/substance3d-3dsmax-win-2025>
* **Download for Autodesk 3dsMax 2024** (plug-in version 3.1.0.): <https://www.adobe.com/go/substance3d-3dsmax-win-2024>
